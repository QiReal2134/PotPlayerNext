## 基准方法（不填写虚构数据）

Release 构建、同一电脑、同一显示缩放，记录 CPU/GPU/内存、OS、文件数量和编码。分别冷启动与系统缓存热启动至少 5 次，报告中位数和 P95：

| 场景 | 指标 | 当前结果 |
|---|---|---|
| 空闲 60 秒 | Private working set / CPU | 本机单次热态：51.61 MiB / 平均归一化 CPU 0.00%；非多轮基准 |
| 1,000 个文件 | 扫描至首屏完成时间 | 未测 |
| 持续滚动 30 秒 | UI 帧时间、峰值内存 | 未测 |
| 4K H.264 播放 60 秒 | CPU/GPU、丢帧、内存 | 未测 |
| 100 次预览开关 | 内存回收后的增长 | 未测 |

缩略图 CPU 缓存粗估：128 × 192 × 192 × 4 ≈ 18 MiB，上界不包括可视容器引用、GPU 纹理、系统 thumbnail 缓存、.NET/WinUI 和媒体解码缓冲，因此不是应用整体内存承诺。长图还需单独测量。

空闲样本：0.2.1 独立主窗口、6 个图片/视频缩略图、预览已关闭，Windows 10.0.26300.0、16 逻辑处理器、125% DPI；约 60.9 秒采样。三次 Private Working Set 均为 54,116,352 字节（51.61 MiB），TotalProcessorTime 未观察到增量。总 Working Set 与 Private Bytes 不等于私有工作集；不据此声称冷启动、4K 播放或长期无泄漏。证据见 docs/evidence/idle-021-20261005.json。
